### 9) الرسم النهائي والتجميع

**الخفيف:**
```bash
node scripts/04_render_frames.js <work> all          # يكمّل من وين وقف — ما يعيد فريماً جاهزاً
bash scripts/06_encode.sh <work> <work>/ad-final.mp4
```
عدّلت مشهداً واحداً بعد الرسم؟ لا تعيد الكل — أعد نافذته بس ثم جمّع:
```bash
node scripts/04_render_frames.js <work> range 26.4 31.2
```
(`--force` مع `all` يعيد الرسم من الصفر. السكربت ينبّهك لو بقي فريم ناقص قبل التجميع.)

**ريموشن:** يطلّع MP4 مباشرة بلا فريمات:
```bash
bash scripts/04b_remotion.sh <work> render <work>/ad-final.mp4
```

## فواحص المحرّك الخفيف (08 · 08b · 08c) — كما كانت بقسم التحقق

0. **المنطقة الآمنة والهوك** — فحص آلي، ما يحتاج عينك:
```bash
node scripts/08_safe_check.js <work> --shot
```
يرسم كل لحظة مرتين بلونين مكان الفيديو، واللي ما يتغيّر = رسمك أنت — فيعدّ نصوصك داخل مناطق أزرار انستقرام بدقة، ويتأكد إن أول كابشن قبل نصف ثانية. يخرج بالرمز 3 لو فيه خرق، ويطلّع `safe.jpg` واللقطة الحمراء توريك وين المشكلة.
الحدود تُعدّل بملف `<work>/safe.json` لو احتجت (مثلاً فيديو للتيك توك بحدود ثانية).

0.2 **الوجه — فحص آلي إلزامي:**
```bash
node scripts/12_face_guard.js <work> check
```
يخرج بالرمز 3 لو أي نافذة تقصّ شعره أو ذقنه. **«شفته باللقطات وبان زين» مو تحقّق** — القص يبان بلحظة وحدة بين لقطتين.

0.5 **التداخل — فحص آلي إلزامي، لا تسلّم بدونه:**
```bash
node scripts/08b_overlap_check.js <work>
```
يعزل رسومات المشاهد وحدها (يطفي الكابشن والشارة، ويحط لوناً صريحاً مكان الفيديو) ويقيس صندوقها كل ربع ثانية، فيمسك ثلاثة أخطاء ما تشوفها بست لقطات:
**رسم فوق وجه المتحدث** · **رسم داخل كرت الكابشن** · **رسم نازل تحت الحد**.
يخرج بالرمز 3 لو فيه خرق. **العين تفشل هنا** — التداخل يصير بلحظة وحدة بين لقطتين، وأربع جولات تصليح تكلّف أكثر من فحص واحد.
حدوده تُعدّل بـ`<work>/safe.json` (`drawBottom`، `videoPad`).

0.7 **تداخل النصوص — فحص آلي إلزامي:**
```bash
node scripts/08c_text_collide.js <work>
```
كل نص يُرسم يسجّل صندوقه، والفاحص يقارن كل زوج. يمسك حالتين:
**تراكب** (نص فوق نص) · **وتلاصق** (أقل من ٢٢ بكسل بينهما — تُقرأ كتلة وحدة).
**الفاحصان الآخران ما يمسكانه** — هما للرسم فوق الوجه وداخل الكابشن. والعين تفشل هنا لأن الفرق ٨ بكسل.
**والحل عادةً تصغير الخط** ليواكب الرسم، مو تكبير المساحة.
