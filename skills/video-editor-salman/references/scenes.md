# تصميم المشاهد — الخطوتان ٧ و٧.٥ (مرجع يُقرأ قبل كتابة أي مشهد)
> الأمثلة بالكانفس للمحرّك الخفيف؛ المبادئ والجداول تنطبق على ريموشن. وقبل ما تصمّم: اقرأ `LEDGER.md` (المرفوض أولاً) و`voice.md` بمجلد بياناته، ودليل الأسلوب اللي اختاره.

### 7) صمّم المشاهد ← أهم خطوة
انسخ `compose.REFERENCE.html` إلى `<work>/compose.html` وأعد كتابة دوال المشاهد.

**البنية جاهزة، لا تلمسها:** تصغير الفيديو داخل كرت (`R_FULL` / `R_STAGE` / `R_SIDE` بانتقال ناعم)، شارة الحساب، شريط التقدّم، كروت الكابشن مع تظليل الكلمة المنطوقة، كرت النهاية، واشتقاق الألوان من الثيم.

**اللي تبتكره:** المشاهد. اعصف ٣-٤ أفكار لكل جملة، والفكرة لازم تكون **استعارة بصرية لما يقوله**، لا زينة:

| يقول | المشهد |
|---|---|
| يعدّد أشياء | بطاقات تدخل وحدة مع كل كلمة ثم تنقلب بعلامة صح |
| رقم أو سعر | عدّاد يلف وينزل على الرقم بضربة |
| «فرّغ كلامي» | لوحة تفريغ، كل كلمة تنزل بسطرها وتوقيتها |
| «انكسر / خطأ» | قليتش يزحزح شرائح الصورة + شقوق |
| مشكلة تقنية | كرت الفيديو يسوَدّ وفوقه علامة تحذير |
| إصلاح | شريط تقدّم + قائمة تتعلّم بصح |
| «ملف واحد» | كرت ملف وبطاقات تطير وتندمج فيه |
| دعوة للتعليق | مربع تعليق والكلمة تنكتب حرف حرف |
| يذكر كتاباً أو مرجعاً | بطاقة الكتاب: العنوان والمؤلف بلون التمييز |
| شدّ وجذب («من جهة… ومن جهة») | فقاعتان متعاقبتان بلونين متضادين بنفس المكان |
| يعدّد مجالاته أو اهتماماته | أقراص تدخل واحداً واحداً بصف واحد تحت الفيديو المصغّر |
| «قبل الموعد بـ٤٨ ساعة» | شارة وقت تنبض مرة وحدة وتثبت |
| يعرض خيارات للجمهور | أقراص مرقّمة تتراكم مع كل خيار يذكره |

**ثلاثة أنماط جاهزة ترسم فوق الفيديو — استعملها بدل ما تعيد كتابتها:**
```js
waveform(t, 3.2, 7.8)                       // موجة صوتية تنبض مع الكلمة المنطوقة
counter(t, 12.0, 16.5, 42195, 'متر')        // عدّاد يلف وينزل على الرقم
meter(t, 20.0, 24.0, 78, 'نسبة الإنجاز')    // شريط نسبة

// صفحة كتاب للاقتباس — بلحظة R_NONE، وأخفِ الكابشن العادي طولها
quotePage(t, 82.0, 86.9, [{t:'السطر الأول من الاقتباس', s:83.35},
                          {t:'السطر الثاني', s:84.45}])

// مقارنة حيّة: المنطوقة تنوّر وتكبر والثانية تخفت
livePair(t, 86.9, 92.7, [{t:'معلومة', s:87.05, on:[87.05,88.55], icon:'check', x:-1},
                         {t:'عيب',    s:88.60, on:[88.60,90.40], icon:'cross', x:+1}])
```
**⛔ الأسلوب البصري المعتمد — خلفية حيّة وأشرطة تتعبّى:**
```js
liveBG(t)                                  // خلفية متدرّجة بتوهّجين يتنفّسان + حبيبات
listRow(x,y,w,h,{n:1,t:'النص',live,fill})  // الرقم يمين ثم النص · شريط يتعبّى يسار←يمين
stepRail(y,items,t,total)                  // دوائر تتحوّل لعلامة صح وخط يمتد
summaryCard(x,y,w,h,'الخلاصة',a)           // كرت فاتح يقلب التباين ويغلق المشهد
```
| القاعدة | ليش |
|---|---|
| **الخلفية باردة والتمييز دافئ** (أو العكس حسب هويته) | لون التمييز فوق خلفية من نفس لونه = «حوسة». وخذ اللون البارد من إضاءة مكان تصويره فيتناغم مع اللقطة |
| **الخلفية ما تكون صامتة** | تدرّج + توهّجان يتحرّكان ببطء + حبيبات — الأسود المصمت يحس ميتاً |
| **ثلاث حالات لكل عنصر** | لسه ما جاء (بارد) · يُنطق الحين (دافئ متوهّج) · خلص (معبّى خافت) |
| **هرمية مو سطر مسطّح** | عنوان + شريط تقدّم + صفوف + شريط مراحل + خلاصة |

**⛔ وبوضع التشخيص (`window.__diag`) ارسم الخلفية مصمتة** — الفاحص يعزل عناصر المشاهد، والخلفية الزخرفية تُحسب رسماً فتعطي إنذاراً كاذباً «نازل تحت الحد».

**⛔ عشر آليات عرض — ولا تكرّر آلية بنفس الفيديو:**

| الآلية | تناسب | الاستدعاء |
|---|---|---|
| عدّاد يلف | رقم كبير | `odometer(cx,cy,38000,k,{label:'رحلة'})` |
| شبكة نقاط | ندرة أو نسبة | `dotGrid(x,y,w,h,cols,rows,oneIdx,k)` |
| دائرة تُقسم | تقسيم ونسب | `donutSplit(cx,cy,r,[{v,s}],t)` |
| بطاقة تنقلب | كشف أو مقارنة | `flipCard(x,y,w,h,'سؤال','جواب',k)` |
| كومة تتراكم | تراكم أو تكلفة | `stackBlocks(cx,baseY,n,k)` |
| أعمدة تنمو | مقارنة رقمين | `growBars(x,baseY,w,[{t,v,s}],t)` |
| صف أيقونات | تعداد مجالات | `iconStrip(cx,cy,[{t,s,icon}],t)` |
| مسار متعرّج | رحلة ومراحل | `windingPath(x,y,w,h,[{t,s}],t)` |
| حلقات متحدة المركز | طبقات وأولويات | `rings(cx,cy,[{t,s}],t)` |
| مقياس بإبرة | وقت أو ضغط | `gauge(cx,cy,r,val,max,k,{label})` |
| صف قائمة | تعداد نصّي | `listRow(...)` — القاعدة العامة |

**السبب:** الشريط اللي يتعبّى آلية وحدة. لو كل تعداد بالفيديو شريط يمتلئ، المستخدم يحس «كلها خطوط وتتعبى، ما فيه إبداع» (قالها حرفياً).
**اختر الآلية من نوع الكلام**: رقم ← عدّاد · مقارنة ← أعمدة · رحلة ← مسار · وقت ← مقياس · ندرة ← شبكة نقاط.

**⛔ والمشهد ينتهي مع جملته.** الكتاب بقي معروضاً ١.٦ ثانية بعد ما انتقل لموضوع ثانٍ — لاحظها فوراً. قارن نهاية كل مشهد بنهاية جملته في `caps.json`.

**⛔ الحركة تشرح كلامه، لا تزيّنه.** «تطلع فقاعة» مو موشن قرافيكس — المستخدم قالها صراحة:
«ما نسوي زوم أوت لأجل الزوم أوت». العنصر المنطوق **ينوّر ويكبر**، وأخوه يخفت.
كلها تاخذ `opt.zone` لو بغيت تحطها بمكان ثانٍ، و`opt.color` للون مختلف.
**الموجة الصوتية بالذات** تُربط بالكلمة المنطوقة من `caps.json` — فترتفع مع صوته فعلاً، مو حركة عشوائية.

كل دالة مشهد تاخذ `t` وترسم حسب توقيت الكلمة من `caps.json` — المشهد يلتصق بالكلمة، لا بتوقيت تقريبي.

**⛔ الكثافة — مشهد كل ١٥ ثانية على الأقل.**
الكابشن وحده مو موشن قرافيكس. فيديو دقيقتين بأربعة مشاهد يحس المستخدم إنه «كلام بس»، ويعطيك ٧ من ١٠ ويسألك ليش.
**احسبها قبل ما ترسم:** `مدة الفيديو ÷ 15` = أقل عدد مشاهد مقبول (فيديو ٢:١٥ ← **٩ مشاهد على الأقل**).
ووزّعها على طول الخط الزمني — لا تكدّس خمسة بالبداية وتترك الدقيقة الأخيرة عارية.
**ونوّع الشكل:** لو كل مشاهدك «فقاعة نص تطلع»، فهي مشهد واحد مكرّر تسع مرات. خلّ ٣-٤ منها **تخرج عن وجهه فعلاً**
(الفيديو يصغّر داخل كرت وحواليه رسم حقيقي: قائمة تتبنى، عدّاد يلف، خط زمني يمتد).

**⛔ الحالات محدودة — والرسم ما يجي فوق وجهه أبداً.**
> ⚠️ **بريموشن الصيغ أربع** (`FULL` · `CARD` · `SIDE` · `NONE`) — القاعدة ٧٧ هي المرجع، والجدول تحت للمحرّك الخفيف.

جرّبنا الرسم داخل كرت الفيديو فطلع يزاحم وجهه والكابشن معاً، والمستخدم رفضه بصراحة: «الرسومات كلها غطت على وجهي».

| الحالة | متى | وجهه |
|---|---|---|
| `R_FULL` | كلام صافي بلا رسم | كامل وكبير |
| `R_CARD` | رسم بسيط — الفيديو ينسحب تحت والرسم فوقه | كامل، والرسم ما يلمسه |
| `R_NONE` | رسم كبير ياخذ راحته (خط بياني · مقارنة · اقتباس) | يختفي تماماً |

**`overlayZone(t)` تعطيك المساحة الصحيحة تلقائياً** حسب الحالة — لا تحسبها بيدك.
**وعدد مرات الاختفاء: مرتان لكل دقيقتين** (٣-٤ لأربع دقائق). أكثر من كذا يحس إنه فقد المتحدث.
**ولا تبدّل الحالة مرتين متتاليتين بأقل من ثانيتين** — يطلع تقطيعاً.

**⛔ وجهه لا يُقصّ — والفحص آلي:**
```bash
node scripts/12_face_guard.js <work> scan     # يكتشف وجهه ويكتب faceAnchor الصحيح
node scripts/12_face_guard.js <work> check    # يخرج بالرمز 3 لو أي نافذة تقصّه
```
يفحص ٤٠ لقطة بكاشف الوجوه (Vision بالماك · mediapipe بالويندوز)، ويحسب المرساة المثلى لكل نافذة.
**الهامش فوق الشعر ضعف اللي تحت الذقن** (١٤٪ مقابل ٦٪) — قص الشعر يبان فوراً وقص الرقبة ما ينتبه له أحد.
**شغّله بعد استخراج الفريمات وقبل تصميم المشاهد.** والمرساة اليدوية آخر حل — خلّه يحسبها.
**⚠️ والزوم بـ`03_cut_zoom.py` يقص من فوق ويطلّع وجهه من الكادر** — لو الحارس اشتكى، حط `"noZoom": true`. واللي يصوّر قريب من الكاميرا غالباً يحتاجها.

**⛔ الخط — لا تلمس أوزانه.**
الملف المرجعي يستعمل وزناً واحداً (`700`) بكل النصوص، وهذا مقصود:
- **طلب وزن غير موجود بالخط يخرّب الفيديو بصمت.** أغلب الخطوط العربية بقوقل فونتس تنتهي عند 700 — تكتب `'900 62px'` فالمتصفح يرمي لك خط النظام بدل خطك، وتطلع أول ثواني الفيديو بخط مختلف عن باقيه.
- **ولا تحمّل الخط قبل `init()`** — هي اللي تحقن وصلة الخط المخصّص. الراسمون الثلاثة يحمّلونه بعدها ويتأكدون بالقياس (`ensureFont`)، ولو ما نزل يطبعون تحذيراً صريحاً. **لو شفت التحذير لا تكمّل** — الفيديو كله بيطلع بخط غلط.

**⛔ المنطقة الآمنة — انستقرام يغطي أطراف الشاشة بأزراره:**

| المنطقة | لا تحط فيها نصاً |
|---|---|
| أعلى | أول 150 بكسل |
| أسفل | آخر 300 بكسل (وحزام حذر من 1500) |
| يمين | 180 بكسل بعرض y من 1100 إلى 1750 (لايك · تعليق · مشاركة) |

الملف المرجعي مضبوط أصلاً: الشارة عند 190، شريط التقدّم عند 1600، وحافة كرت الكابشن السفلى 1500.
**وأول كابشن لازم يبان بأول نصف ثانية** — الهوك المتأخر يخسر نصف المشاهدين قبل ما يبدأ الكلام.

عاين قبل ما ترسم كل شي:
```bash
node scripts/04_render_frames.js <work> preview 4.6 12.3 27.6 31.0 48.4
bash scripts/07_contact_sheet.sh <work> <work>/sheet.jpg 4.6 12.3 27.6 31.0 48.4
```

**فتحت له شاشة التعديل؟** المشاهد تنكتب بـ`<work>/Scenes.tsx` (نفس المنطق: كل مشهد ياخذ `t`):
```bash

bash scripts/04b_remotion.sh <work> studio           # تايم-لاين حي على المتصفح
```

مستطيلات عرض الفيديو تنكتب بـ`<work>/stage.json` ونصوص الختام بـ`<work>/outro.json` — وتنعكس بالمحرّكين.
**اقرأ `sheet.jpg` وحدها — لا تقرأ الصور وحدة وحدة.** ورقة واحدة = قراءة واحدة بدل خمس. **لا ترسم الفيديو كامل قبل ما تعاين ٦ لقطات على الأقل**، واعرض الورقة على المستخدم.

### 7.5) الكلام يمرّ ورا الشخص (اختياري — بس قوي)

الكلمة تنكتب كبيرة، وتُمدّ بالكشيدة العربية بمقدار عرض جسم المتحدث، فالكشيدة وحدها تمرّ ورا راسه
والحروف تبقى بارزة على الجانبين. يشتغل بمكتبة ماك المدمجة (Vision)، وبالويندوز بـmediapipe.

```bash
node scripts/11_behind_text.js <work> plan        # يرشّح الجُمل المناسبة
node scripts/11_behind_text.js <work> build 8     # يقصّ الشخص بفريمات هالجملة
node scripts/04_render_frames.js <work> all --force
node scripts/11_behind_text.js <work> off         # إلغاء
```

**⛔ متى تستخدمه — القاعدة:**
1. **مرة وحدة بالفيديو، وأفضل مكان الهوك.** لو عندك لحظة ثانية تستاهل، استعمل `quotePage` بدلها — كل تقنية تاخذ لحظة وحدة فما يحس بالتكرار.
   والهوك عادةً جملة طويلة، فاختر منها كلمات: `build 1:9-11` (الكلمات ٩→١١ من الجملة الأولى).
2. **الأفضل بالهوك** (أول جملة) أو بذروة الفكرة — الجملة اللي تبيه يحفظها.
3. الشروط اللي يفحصها السكربت: الجملة **من كلمة لأربع** · مدّتها ≥ 0.85 ثانية.
4. ويشتغل **بلحظات ملء الشاشة فقط** — لو الفيديو داخل كرت صغير بتلك اللحظة، يتخطّاها وحده.
5. كرت الكابشن العادي **يختفي تلقائياً** بهاللحظة حتى ما يتكرر النص مرتين.
6. لو الجملة طويلة أو الشخص واقف بحافة الكادر، الخط يصغّر نفسه — وإذا ما بقي مكان للحروف، لا تصرّ عليها.
7. **الكتلة تقف عند رأسه فما فوق** — لا تنزل لصدره، والحجم يُشتق من المساحة فوق رأسه لا من رقم ثابت.
8. **عرض الكشيدة يُحسب مرة وحدة ويثبت** (`_BTC`). قياسه كل فريم كان يخليه يرتجف ٣٠ مرة بالثانية مع أنفاس المتحدث — أوضح عيب لاحظه المستخدم.
9. **اللون:** خلفية فاتحة ← نص غامق · خلفية غامقة ← نص فاتح. (كان مقلوباً بالكود فطلع نصاً أسود على خلفية سوداء.)

**التكلفة:** ~٠.١٥ ثانية لكل فريم للقصّ (جملة ثانيتين ≈ ١٠ ثوانٍ شغل). بالماك يحتاج أدوات Xcode، وبالويندوز mediapipe (`00_setup.sh` يجهّزها)؛
وإذا ما توفّرت، السكربت يقول لك بجملة وحدة وباقي الخط يشتغل عادي.
