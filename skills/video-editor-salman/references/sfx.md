# المؤثرات الصوتية — الخطوة ٨ (مرجع)
> الأصوات المركّبة بالكود (`05_sfx.py`) للأسلوب البسيط. أساليب الكولاج والوثائقي واللوح تستعمل مكتبة أصوات حقيقية (`styles/collage/mix_sfx.py` + `sound_add.py`). والمرفوض عند المستخدم بسجلّه (`LEDGER.md`).

### 8) المؤثرات الصوتية
```json
{ "outro": 5.2, "whoosh_up": [3.1,11.25], "whoosh_down": [7.85],
  "thud": [27.27,29.47], "tap": [23.08,24.06] }
```

**الكثافة — حدّان منفصلان، لأن النوعين ما يتعبان الأذن بنفس الطريقة:**

| النوع | الحد | ليش |
|---|---|---|
| **انتقالات** (whoosh · tap · thud · swipe · ding) | ≤ **١٠**/دقيقة | مجرّدة ومتكررة — الزيادة فيها تصير ضجيجاً |
| **الإجمالي** | ≤ **٢٠**/دقيقة | الدلالية مربوطة بكلمة يقولها، فما تتعب — وهي مصدر الإحساس بالإبداع |

أقل من ١٠ إجمالاً يحس المستخدم إن «الصوتيات قليلة ومافيها إبداع». السكربت يطبع الرقمين ويحذّر لكل وحدة على حدة.
**١) أصوات الانتقال — تُربط بحركة بصرية:**

| النوع | يجي مع |
|---|---|
| `whoosh_up` | مشهد يدخل · الفيديو يصغّر داخل كرت |
| `whoosh_down` | مشهد يخرج · الفيديو يرجع ملء الشاشة |
| `swipe` | عنصر يُستبدل بعنصر |
| `thud` | رقم ينزل · شي ينكسر · تأكيد ثقيل |
| `tap` | عنصر يدخل بقائمة · قرص يظهر |
| `ding` | علامة صح · إنجاز |

**٢) الأصوات الدلالية — تُربط بما يقوله فعلاً ← هنا يجي الإحساس بالإبداع:**
> ⛔ تُسمع طفولية أو مزعجة غالباً: `riser` · `drop` · `clock` · `knock` · `countdown` · `breath` (القواعد ٢٧ و٥٥ و٨٣) — لا تستعملها إلا بطلبه. وصفّارة فوق ٤ كيلوهرتز، محسوبة بميزانية ≤2/دقيقة: `swipe` · `tap` · `shutter` · `glass` · `type` — بدائلها `pip` و`pulserun` ومكتبة الأصوات الحقيقية.

| الصوت | يجي لما يقول |
|---|---|
| `steps` | جري · مشي · «طلعت أركض» (إيقاع ١٧٦ خطوة/دقيقة، إيقاع الجري الحقيقي) |
| `metal` | حديد · أثقال · تمرين مقاومة |
| `jet` | طيران · سفر · إقلاع · «مليون رحلة» |
| `heartbeat` | توتر · خوف · لحظة حاسمة · مجهود |
| `dread` | خطر · موت · «لو غلطت راح تخسر» — طبقة منخفضة تهبط |
| `shutter` | تصوير · صورة · لقطة |
| `coin` | فلوس · سعر · تكلفة · اشتراك |
| `type` | كتابة على كيبورد · رسالة · تعليق |
| `paper` | «جيب ورقة» · صفحة تنقلب · دفتر |
| `write` | «وقلم» · خربشة · تدوين ملاحظة |
| `ticker` | عدّاد يتسارع — رقم يصعد أو يُحسب |
| `cash` | فلوس · سعر · «دفعت» · اشتراك |
| `glass` | خطأ مكلف · شي انكسر · «دفعت ثمنها» |
| `lock` | قرار حاسم · «ما يسرق حياتي» · إغلاق |
| `hookrise` | توتر صاعد بأول الفيديو — يشدّ قبل ما يتكلم |

**القاعدة:** الصوت الدلالي يجي **عند الكلمة نفسها** من `caps.json`، لا قبلها ولا بعدها. قال «حديد» ← `metal` بتوقيت الكلمة بالضبط.
**ولا تكرر الصوت الدلالي الواحد أكثر من مرتين** بالفيديو، وإلا انقلب من مفاجأة لتكرار.
السكربت يطبع الكثافة والذروة ويحذّرك لو خرجت عن المدى.

**اشتق أوقات أصوات الانتقال من دوال المشاهد نفسها**، لا تكتبها بالعين: كل `pr(t,a,b)` ببداية مشهد = `whoosh_up` عند `a`، وكل عنصر بقائمة له وقت دخول = `tap`.
**وأصوات الدلالة اشتقها من النص:** امسح `caps.json` عن الكلمات المفتاحية (جري، حديد، طيران، فلوس…) وخذ توقيت الكلمة نفسها.
```bash
python3 scripts/05_sfx.py <work>
```
