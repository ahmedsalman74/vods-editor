# Engine provenance and license scope

This directory includes the complete engine supplied by the repository owner as `video-editor-bassam`, including installed stream-editing additions, and is packaged at their explicit request as `video-editor-salman`. The rename does not claim authorship of the original engine.

No blanket license for the original engine code was present in the supplied archive or installed copy. **The repository's root MIT license does not apply to this imported directory.** Inclusion here does not establish an unrestricted open-source license for the original engine. Existing asset-specific licenses and source notices remain applicable: see `styles/collage/assets/SOURCES.md` and `ArefRuqaa-OFL.txt`. Remotion and other dependencies retain their own terms.

`SOURCE_FILES.json` records the supplied snapshot's file hashes before packaging changes. Local changes are limited to the skill's installation/name instructions, compatible data-directory selection in `_paths.py` and `_paths.js`, one trailing-space cleanup in `04b_remotion.sh`, and packaging/setup/provenance documentation. Generated bytecode is excluded. No user profiles, recordings, transcripts, credentials or rendered projects were copied.

The full renderer and checks are included, but external runtimes, model weights, music libraries and project-specific media are not. Their installation and applicable terms are separate from copying this skill.
