# أفكار «عالم المقطع» ومراجع بنترست

كل مقطع يستاهل **عالماً واحداً** تنبني فيه كل المشاهد: مكان أو شي مادي من موضوعه نفسه، ونفس الأدوات تتلوّن فيه.
العالم الموحّد يخلّي المقطع يبان مصمَّم، مو مشاهد متفرّقة. ولا تعيد نفس العالم بالمقطع اللي بعده.

## كيف تختار العالم
1. **اسأله: وش موضوعك؟** وش الشي المادي اللي يخطر ببالك لما تفكر فيه؟
2. **دوّر شي من عالم الموضوع نفسه** — مقطع عن المال: كشف حساب، محفظة، شاشة تداول. عن النوم: غرفة، ساعة منبّه. عن الكتب: طاولة قراءة، رفوف.
3. **خلّ الرسومات «تعيش» داخله** — الأرقام تنكتب على الورقة، الصور تنعلّق على الحائط، الكاميرا تتحرك بين أجزائه.
4. **اعرض عليه ٢–٣ عوالم** بجملة لكل واحد (وصورة مرجع لو تقدر) قبل ما تبني.

## أفكار عامة للعوالم
| العالم | يناسب | الفكرة |
|---|---|---|
| **طاولة مكتب من فوق** | القصص والدراسات | أوراق وصور تنحط على الطاولة حول وجهه، ويد تكتب |
| **حائط تحقيق** | الألغاز والقصص | صور ودبابيس وخيط أحمر يربط الأدلة (أسلوب كولاج الورق) |
| **خريطة قديمة** | الأماكن والرحلات والتاريخ | الكاميرا تطير بين المحطات، والأحداث تنعلّم على الخريطة |
| **دفتر أو سبورة** | الشرح خطوة بخطوة | الخطوات تنكتب بخط اليد وتنشطب وتتلوّن |
| **شاشة جوال عملاقة** | التقنية والعادات الرقمية | التطبيقات والإشعارات بحجم كبير قدامه، والمشاهد داخل الشاشة |
| **أرشيف أو جريدة قديمة** | التاريخ والأخبار | قصاصات جرايد حقيقية، ورق مصفرّ، تلفزيون قديم |
| **مختبر أو لوح أرقام** | الدراسات والإحصاءات | أعمدة وعدّادات ورسوم بيانية بشكل أدوات قياس حقيقية |
| **لوح مخطط داكن** | القرارات والأنظمة | عقد وأسلاك ونبضة تمشي (أسلوب لوح المخطط) |
| **عالم مصغّر** | أي موضوع فيه شي واحد مركزي | الشي الرئيسي بحجم ضخم وحوله عالم صغير يتحرك |
| **كشف حساب أو فاتورة** | المال والأسعار | الأرقام تنطبع على ورق مطبعي قديم، والأحمر للخسارة |

## «جيب لي أفكار» — كلمات بحث بنترست حسب الموضوع
لما يطلب أفكار، اسأله عن موضوعه، وأعطه **٤–٦ كلمات بحث بالإنجليزي** يبحث فيها بنترست ويرجع لك بالروابط أو الصور اللي عجبته:

| موضوعه | كلمات البحث |
|---|---|
| كتب وأفكار | `book summary animation` · `editorial collage motion` · `paper cutout explainer` |
| دراسات وأرقام | `data storytelling motion graphics` · `infographic animation vertical` · `newspaper collage video` |
| مال واستثمار | `finance explainer animation` · `stock chart motion design` · `retro receipt design` |
| صحة ورياضة | `fitness motion graphics` · `anatomy illustration animation` · `health infographic collage` |
| تقنية وجوال | `phone ui motion design` · `app interface animation` · `isometric tech illustration` |
| تاريخ وقصص | `archive documentary style` · `vintage map animation` · `old newspaper collage` |
| تطوير ذات | `minimal typography motion` · `hand drawn explainer` · `notebook sketch animation` |
| أعمال وتسويق | `business explainer vox style` · `investigation board collage` · `corporate motion graphics bold` |

وكل مرجع يرسله يتحلّل بأربعة محاور (مو الشكل بس): **الأشكال · الكاميرا · الصوت · الإيقاع** —
`scripts/ref_fetch.sh <رابط>` يحفظ شبكة إطارات، و`scripts/ref_measure.py` يقيس الكاميرا والصوت بالأرقام.
وأفكار المرجع تُقترح مكاناً مكاناً، لا تتعمّم على كل المشاهد (القاعدة ٨٨).
