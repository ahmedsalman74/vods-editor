# Resolve Studio: direct native MCP

Use **DaVinci Resolve Studio 21.1** for this documented route. Blackmagic's [21.1 reference manual, page 4318](https://documents.blackmagicdesign.com/UserManuals/DaVinci_Resolve_21.1_Reference_Manual.pdf#page=4318) describes its built-in MCP and the **File → Setup AI Assistants** command. It explicitly mentions Claude Desktop and Claude Code. Use the setup confirmation to see which assistants your installation detected; do not assume Codex was registered without checking.

1. Install Studio and the assistant, then launch each once.
2. Install this workflow's skills/helpers:

   ```powershell
   py -3.12 scripts/setup.py --edition studio --client claude-code --analysis
   ```

   Choose `codex` or `all` as appropriate. This mode preserves MCP settings and does not install/register the community bridge.
3. In Studio choose **File → Setup AI Assistants** and wait for its confirmation.
4. Restart the detected assistant. Inspect its MCP list/settings and available tools.
5. Ask it to report the currently open project's name and timeline count, with no project changes or saves. Discover tool names from the native server; the Free bridge's `resolve_status` name is not a promise about Studio's schema.

If Codex is not detected, inspect the connection configuration generated by Studio and its installed documentation. Add that exact executable/arguments or endpoint to Codex's MCP configuration; do not guess a port or substitute the community bridge and call it native. Current [Codex MCP configuration documentation](https://developers.openai.com/codex/mcp/) describes stdio and URL server registration. Never publish local credentials or generated configuration.

When switching from Free, first verify the native connection, then disable the old `davinci-resolve` community registration in that client's settings to avoid two active editing connections. Keep a backup; do not delete unrelated MCP servers. No Lua bridge script is needed for the native route.

The **External scripting using → Local** preference applies to external scripting API integrations. It is not a replacement for the native **Setup AI Assistants** flow. The older Python/community route is outside this project's tested setup.

This Studio route was checked against the official manual, not live-tested: the development PC runs Free 21.1.0.17. If the menu is absent, verify the exact edition/version rather than assuming “connected.”
